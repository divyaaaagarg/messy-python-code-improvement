# Messy Python Code Improvement

This project demonstrates how a hard-to-read Python script can be refactored into smaller, clearer functions without changing its intended result.

## Files
- `messy_code.py` — original intentionally repetitive version.
- `improved_code.py` — refactored version using functions, validation, and clearer names.
- `sample_input.txt` — example values used for demonstration.

## Technologies
- Python 3

## Run locally
```bash
python messy_code.py
python improved_code.py
```

Both scripts use the same sample data and print a summary of marks and the average.

## Improvements demonstrated
- Replaced repeated calculations with reusable functions.
- Used descriptive variable names.
- Added basic validation for empty input and invalid marks.
- Separated data, calculation, and display logic.
- Added type hints and docstrings in the improved version.

## Note
The original script is intentionally messy for comparison and learning purposes.
